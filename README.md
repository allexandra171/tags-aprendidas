<p>:Define um parágrafo;
<abbr>:Define uma abreviação;  
Utlizei também as todas as tags utilizadas nas aula:
<h1> até <h6>: Dedine o títulod de diferentes níveis de importancias.
<p>: Representa um parágrafo  de texto.
<mark>:indica uma parte do conteúdo do documento que provavelmente é relevante para a atividade atual do usuário. Isso pode ser usado, por exemplo, para indicar as palavras que corresponderam a uma operação de pesquisa.
<small>:serve para definir textos de tamanho menor, indicando comentários laterais, notas de rodapé, direitos autorais ou avisos legais (o chamado "texto pequeno").
<i>:elemento em itálico, mas, por definição, não é mais obrigado a fazê-lo.
<u>:Define sublinhado. (Apenas efeito visual);
<strong: Define um texto forte (similar ao negrito);
<ol>:Define uma lista ordenada;
<ul>:Define uma lista desordenada;
<li>:Define os itens da lista;
<a>:Define um hyperlink;
<hr>:Define uma regra horizontal. (Tem o mesmo nível que um parágrafo, mas também é utilizado para fazer separações e quebras de linha);
<sub>:Define um texto subscrito;
<sup>:Define um texto sobrescrito;
